# House Price Prediction

A Jupyter notebook that **analyzes a housing dataset** and applies statistical analysis and machine learning to **predict property prices**.

## Overview

Explores the housing data through data analysis, exploratory visualisation, and regression modelling, with the goal of predicting house prices from available features.

## Features

- Exploratory data analysis of housing data
- Statistical summaries and visualisations
- Machine learning price prediction

## Tech Stack

Python, Jupyter, Pandas, scikit-learn / regression.

Completed data-science project.
